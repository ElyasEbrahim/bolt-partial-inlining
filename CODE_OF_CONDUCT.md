# Code of Conduct

This project follows the
[LLVM Community Code of Conduct](https://llvm.org/docs/CodeOfConduct.html):
its code is meant to be contributed to the LLVM project, and the same
standards apply here. They cover all project spaces, including issues, pull
requests and reviews.

To report a concern, contact the maintainer (GitHub user ElyasEbrahim)
through GitHub. Reports are handled confidentially.
